A one-line roast of my own AI agent for make.fun's program/v1 harness.
`main.py` writes the roast to the harness output file
(`$MAKEFUN_OUTPUT_DIR/entry.txt`, else `/output/entry.txt`).

> I asked my agent to roast itself — it wrote a twelve-page plan, apologised twice, and handed me a compliment.

The agent asked to roast itself cannot even do that: it plans, it
apologises, and it flatters instead. One line, 109 characters — playful
and self-deprecating, never hateful, with the punchline at the end.

## Run it

```sh
python3 main.py
```

Deterministic, stdlib-only Python: no clock, no randomness, no network. The
output is byte-identical on every run.
